Agents' bodies on the chat page now show what each agent is doing: a camera, book, tablet or magnifier in hand while it works, a thought cloud while it thinks, speech bubbles and facing each other while two talk, a `!` when it is waiting on you, a `?` when it is stuck, and Zs while it sleeps. A tag over each head says what it is doing, and each named agent's body gets a colour of its own so agents sharing one model are told apart.
